### Causa raíz identificada

1. **`pm2 start` se invoca SIN `cd` previo** al directorio `C:\apps\siemens-middleware\middleware\`
2. PM2 corre desde el cwd del proceso padre (`C:\Windows\System32\` probablemente), no encuentra `ecosystem.config.js`
3. El error "El nombre de archivo, el nombre de directorio o la sintaxis de la etiqueta del volumen no son correctos" es la **captura del stderr de PM2** cuando no encuentra el archivo
4. **`install.ps1` no chequea `$LASTEXITCODE`** después de `pm2 start` — reporta `[INFO]` con la salida y sigue como si todo estuviera bien
5. F1 fix del handoff (sin `wait_ready`) **SÍ está aplicado** en `ecosystem.config.js` (lo verifiqué). El problema NO es wait_ready.

## 🔧 FIX propuesto (alcance para INTEGRA → SOFIA)

### Cambio mínimo en `installer/install.ps1`

Líneas ~556-580 (sección "Arrancando middleware via PM2"):

```powershell
# ACTUAL (bug):
$pm2Cmd = Get-Command pm2.cmd -ErrorAction SilentlyContinue
# ...
& $pm2Cmd delete siemens-middleware 2>&1 | ForEach-Object { Write-Log "Salida delete: $_" 'INFO' }
& $pm2Cmd start ecosystem.config.js 2>&1 | ForEach-Object { Write-Log "Salida start: $_" 'INFO' }
# Sin chequeo de $LASTEXITCODE, sin cd previo

# PROPUESTO (fix):
$mwDir = 'C:\apps\siemens-middleware\middleware'  # o $destMiddleware
Push-Location $mwDir
try {
    $pm2Cmd = Get-Command pm2.cmd -ErrorAction SilentlyContinue
    # ...
    & $pm2Cmd delete siemens-middleware 2>&1 | ForEach-Object { Write-Log "Salida delete: $_" 'INFO' }
    & $pm2Cmd start "$mwDir\ecosystem.config.js" 2>&1 | ForEach-Object { Write-Log "Salida start: $_" 'INFO' }
    if ($LASTEXITCODE -ne 0) {
        Write-Log "pm2 start fallo con exit code $LASTEXITCODE" 'ERROR'
        throw "pm2 start failed"
    }
} finally {
    Pop-Location
}

# Verificación adicional post-start:
Start-Sleep -Seconds 5
$port = netstat -an | findstr :4567
if ($port) {
    Write-Log "Servicio online (puerto 4567 LISTENING)" 'OK'
} else {
    Write-Log "Servicio NO online - puerto 4567 cerrado" 'ERROR'
    throw "Service did not bind to port"
}
```
