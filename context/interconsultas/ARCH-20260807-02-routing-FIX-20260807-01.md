## 4. Mini-SPEC para SOFIA (contrato de delegación)

**ID tarea:** FIX-20260807-01 → implementación SOFIA (prefijo IMPL-20260807-04 al reportar)
**Alcance:** hacer que el sub-paso "Arrancando middleware via PM2" del instalador deje el servicio realmente online y falle ruidosamente si no lo logra.

**Archivos:**
- `installer/install.ps1` — sección "Arrancando middleware via PM2" (~líneas 556-600). Ver propuesta concreta en `FIX-20260807-01-handoff.md` §"FIX propuesto".
- `installer/VERSION` — bump PATCH a 12 (v2.0.12).
- `installer/installer.iss` — sin cambios (confirmado en handoff).

**Criterios de aceptación:**
1. `pm2 start` se ejecuta con cwd = directorio del middleware (`Push-Location`/`Set-Location` + restauración posterior), pasando la ruta absoluta de `ecosystem.config.js`.
2. `$LASTEXITCODE` se captura ANTES de cualquier pipe (`ForEach-Object` no lo propaga — edge case explícito del handoff). `pm2 start` con exit code ≠ 0 aborta la instalación con error claro en log.
3. Fallo en `pm2 delete` NO aborta (limpieza idempotente; puede no haber instancia previa). Solo `pm2 start` es fatal.
4. Verificación post-start del puerto 4567 con POLLING Y TIMEOUT (no chequeo único): el handoff documenta que el bind tarda más de 5s en warm-up. Sugerencia: reintentos cada 2-3s hasta 30s. Si no bindea → error claro, instalación falla (nada de "INSTALACION COMPLETADA EXITOSAMENTE" con servicio caído).
5. Resolución de `pm2.cmd`: `Get-Command` primero, fallback a path absoluto `%APPDATA%\npm\pm2.cmd`. Si ninguno existe → error claro.
6. El log distingue niveles reales: stderr de pm2 no se registra como `[INFO]` de éxito.
7. Sin cambios de comportamiento en los otros 7 pasos del wizard. Sin tocar `.env`, credenciales ni `FIREBIRD_PASSWORD`.

**Validaciones obligatorias (DoD):**
1. Parser de sintaxis PowerShell sobre `install.ps1` modificado.
2. Recompilar `.exe` v2.0.12 con ISCC en la VM.
3. E2E en VM limpia: `pm2 kill` + borrar `C:\apps\siemens-middleware` → ejecutar instalador → verificar `pm2 list` online, `Get-Process node`, puerto 4567 LISTENING, UI responde, login Admin/Admin123.
4. Evidencia: extracto del nuevo `install.log` mostrando el sub-paso PM2 con verificación de puerto OK.
5. Self-review manual (Qodo está sunset): ¿refleja la mini-SPEC? ¿edge cases cubiertos? ¿riesgo de regresión en otros pasos?
6. NO commit/push/PR. NO tocar el workaround activo (pm2 PID 4392) salvo para la prueba E2E de reinstalación limpia.

**Fuera de alcance (no tocar ahora):**
